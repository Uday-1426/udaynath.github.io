Smart Waste Management

Sensors that tell the collection team when a bin is full, so bins are emptied on time instead of on a fixed schedule.

  • ESP32
  • Ultrasonic Sensor
  • KiCad
  • ThingsBoard
  • UltrasonicFill-level sensing
  • ESP32Controller
  • AlertsTo the team

01. The problem

In a factory, different bins fill up at different speeds. With a fixed collection schedule, some bins overflow while others are emptied half-full. The team needs to know the real status before they plan their round.

02. What we built

An ultrasonic sensor in each bin measures how full it is. An ESP32 reads the level, shows it on a local web server, and alerts the factory team when a bin needs emptying.

03. Key points

What it does

  • Real-time monitoring and triggering using ultrasonic sensors.
  • Alerts sent to the factory team for on-time disposal.
  • Monitoring through a local web server.
