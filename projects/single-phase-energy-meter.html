Single Phase Energy Meter

A connected meter for homes that shows more than one total. It measures voltage, current, power, power factor and temperature, and it is affordable.

  • ADE7753
  • KiCad
  • ThingsBoard
  • Arduino IDE
  • IoT
  • 5Things measured
  • LiveCT calibration
  • GrantedPatent

01. The problem

Most homes see electricity as a single number on the monthly bill. It tells you how much you used, but not how. Is the voltage steady? Are appliances using power efficiently? Is something getting hot?

02. What we built

A meter using the ADE7753 chip that measures voltage, current, power, power factor and temperature, and sends the readings to a ThingsBoard dashboard. We kept the cost low so it makes sense for a single household.

03. Key points

What it does

  • Real-time CT calibration.
  • Measures voltage, current, power, power factor and temperature.
  • Patent granted (Patent ID 202341080081).

How it works

  1. SupplySingle-phase mains
  2. CTCurrent sensing
  3. ADE7753Metering chip
  4. ControllerReads and sends data
  5. DashboardRemote monitoring

Calibration where it is fitted

Current transformers are not all the same. With real-time CT calibration, the meter can be tuned at the place where it is installed, so the readings stay accurate.
